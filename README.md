# Tower Defence

A browser tower-defense game, built one step at a time.

## Play it

Download **`tower-defense.html`** and open it in a browser. That's it — one file, no server, no internet, no build step. Everything (HTML, CSS, JS) is inside it.

The step-by-step build (`index.html`, `style.css`, `main.js`) is the long form of the same project: steps 0–9 are plain static HTML/CSS/JS, and step 10 adds a Flask + SQLite leaderboard.
